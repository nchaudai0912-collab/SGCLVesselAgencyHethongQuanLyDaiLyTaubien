# SGCL Vessel Agency — Hệ thống Quản lý Đại lý Tàu biển (Multi-Voyage Full-Stack)
Thực hiện & Phụ trách: **Trương Nguyễn Bảo Ngọc**

## Cách chạy trên máy (Local)
```bash
npm install
npm start
```
Mở trình duyệt tại `http://localhost:3000`.

## Cách cập nhật lên GitHub & Render.com
1. Giải nén file `.zip`, mở vào bên trong thư mục để thấy `package.json`, `server.js`, `render.yaml`, `public/`.
2. Kéo thả toàn bộ các file/thư mục bên trong lên kho GitHub (đè lên file cũ) → bấm **Commit changes**.
3. Render sẽ tự động build & deploy lại trong 1–2 phút.
